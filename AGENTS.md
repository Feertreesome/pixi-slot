# AI Agent Instructions

This is a PixiJS + TypeScript project.

## Core Rules

- Do not recreate the project.
- Do not replace the existing engine.
- Do not create a parallel engine.
- Do not rewrite navigation, resize, audio, or UI systems unless explicitly requested.
- Do not install new libraries unless explicitly requested.
- Do not move existing files unless explicitly requested.
- Prefer small focused changes.
- Always inspect existing patterns before adding code.
- Use existing UI components when possible.
- Keep TypeScript strict friendly.
- Avoid large files.
- Explain changed files after every task.

## Working Style

- Read nearby code before editing.
- Match existing PixiJS, TypeScript, import, and naming patterns.
- Keep rendering code, game logic, and configuration separated when possible.
- Reuse existing assets, components, utilities, and engine services before adding new ones.
- Keep changes scoped to the requested feature or fix.
- If a request requires architectural changes, explain the impact before making them.
